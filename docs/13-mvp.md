# MVP

The first usable version does not need every feature.

Build this first:

* 1×1 insert
* 38×38 mm plate
* configurable height in Gridfinity units
* L-shaped supports
* circle preset
* capsule preset
* rounded rectangle preset
* multiple shapes
* drag positioning
* numeric dimensions in mm
* live 3D preview
* STL export

Then add:

* SVG import
* arbitrary Gridfinity sizes
* clearance offsets
* project save/load
* shareable URLs
* automatic layout tools
